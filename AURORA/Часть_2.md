**1. Связывание данных**

Формула: XLOOKUP. 
Для суммы: =XLOOKUP(A2; Сделки!$B$2:$B$2000; Сделки!$C$2:$C$2000; 0). Для даты — аналогично, меняя третий аргумент на диапазон дат.
Почему: Функция ищет по всему массиву, не ломается при перестановке столбцов в листе «Сделки» (в отличие от VLOOKUP) и работает быстрее INDEX + MATCH. Аргумент 0 в конце гарантирует точный поиск. Если сделка не найдена, формула вернет 0 (или #N/A, если убрать 0), что сразу подсвечивает «грязные» данные.

**2. Сводный анализ**

1) Выделить таблицу «Лиды» -> Вставка -> Сводная таблица (на новый лист).
2) Перенести поле «Дата» в Строки, нажать правой кнопкой -> Группировать -> выбрать только «Месяцы» и «Годы».
3) Перенести «Канал» в Столбцы.
4) Перенести «ID лида» в Значения (получим количество сделок).
5) Перенести «Сумма сделки» в Значения (получим выручку).
6) Средний чек:
   А) Кликнуть на поле выручки в таблице -> Параметры полей значений -> Дополнительные вычисления -> Доля от... -> Сумма по полю "Количество сделок".
   Б) Либо через Вычисляемое поле: ='Сумма выручки' / 'Количество сделок'.

**3. Сложная формула**

Логика: Нужно посчитать уникальные ID, поэтому обычное COUNTIFS даст общее число строк, а не лидов. Используется формула массива на базе FREQUENCY (ЧАСТОТА) или современный UNIQUE + FILTER.
Формула (универсальная, через массив): 
=СУММ(--(ЧАСТОТА(ЕСЛИ((Лиды!C$2:C$10000="Яндекс")*(Лиды!E$2:E$10000="Иванов")*(МЕСЯЦ(Лиды!B$2:B$10000)=3)*(F$2:F$10000>0); Лиды!A$2:A$10000); Лиды!A$2:A$10000)>0)) 
Вводится нажатием Ctrl+Shift+Enter.
*Пояснение условий:*
C — Канал («Яндекс»), 
E — Менеджер («Иванов»), 
B — Дата (проверка месяца = 3), 
F — Сумма сделки (проверка >0, чтобы отсечь лиды без сделок).
